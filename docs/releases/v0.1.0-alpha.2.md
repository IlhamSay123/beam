# Beam 0.1.0-alpha.2: Vault, safer retries and pairing reset

A self-contained Windows x64 alpha for transferring files and notes between a
PC and iPhone over a trusted local network. No Shortcut, Beam account or separate
.NET installation is required for the normal Safari workflow.

## Changes since alpha.1

- Phone Vault for retained beams in both directions, with search, filters,
  image/note previews and repeat copy/download.
- File-type motion on the phone, desktop workspace and compact pill, including
  reduced-motion support and clearer queue/receipt states.
- First-launch pairing setup, refreshable adapter selection, synchronized QR and
  manual addresses, local connection checks and redacted diagnostics.
- Recent authenticated phone activity on Windows and foreground/retry recovery
  in Safari.
- Safer Safari retries: saved PC receipts and the original transfer ID confirm an
  already received item without another copy, including across a clean PC restart.
- Confirmed PC-only Reset pairing: a new persisted token/QR revokes every old
  browser, QR and Shortcut together. Active transfers are cancelled/drained before
  success; Vault files, history and receipts remain. Failed token replacement
  leaves the previous pairing active. Query-bearing request logs are suppressed.
- .NET 10 with bundled runtime 10.0.13 and updated dependency/test tooling.
  The legacy vulnerable dependency chains are removed; full NuGet auditing stays
  enabled and reported vulnerabilities fail restore/build.

## Install or upgrade

1. Download Beam-0.1.0-alpha.2-win-x64.zip and its .sha256 file below.
2. Quit any running Beam instance. Extract the complete ZIP into a fresh folder.
3. Open Beam.App.exe and follow START-HERE.txt. Keep all published files together.
4. Open Pair phone and scan the QR if needed. Refresh Safari after upgrading.

Existing Documents/Beam files, history and pairing are reused. Updating alone
does not rotate the token. Choosing Reset pairing requires scanning the new QR
on every browser and updating any Shortcut's X-Beam-Token header.

To verify the download in PowerShell, run Get-FileHash on the ZIP with
-Algorithm SHA256 and compare it with the complete hash in the .sha256 file.

## Alpha limits

This is an unsigned prerelease using unencrypted local HTTP and a shared bearer
token. Keep it on a trusted LAN; do not port-forward it or share a live token/QR.
There is no per-device revocation, automatic expiry, signed installer or updater.
Reset cannot recall data already copied or saved on a phone.

Keep Safari open during transfers. Retry the original upload row; reloading,
clearing it or selecting the file again loses that job's retry identity and can
create another copy. Legacy headerless Shortcuts do not use the safe-retry
protocol. Uploads are not chunk-resumable, and abrupt power/disk loss is outside
the receipt guarantee. Downloads still prepare a browser-memory blob before Save.

Default limits remain 100 MiB per file and 64 KiB UTF-8 per note. Not every iOS
version, picker, large-file case, Windows notification or mixed-DPI setup has
been verified.
