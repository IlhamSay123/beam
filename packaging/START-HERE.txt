BEAM 0.1.0-alpha.3 - TRUSTED LAN ALPHA

1. Run the Setup EXE for a per-user install, or extract the complete portable
   ZIP to a folder and keep its files together. Setup adds a Start menu shortcut;
   a desktop shortcut and Windows startup are optional and off by default.
2. Open Beam on your Windows PC. No .NET installation is required.
3. Allow Beam on your trusted private network if Windows prompts.
4. Put the iPhone and PC on a reachable local network.
5. Pairing opens the first time. Later, click Pair phone. Select the address
   for the PC's shared network and scan its QR with the iPhone camera.
6. Safari opens Beam. Use Send for photos, videos, files, notes and links.
   Use Receive for files and text queued from the PC.
   Vault keeps previous beams in both directions while the PC is available.

UPGRADING FROM AN EARLIER ALPHA
Quit the old Beam instance before running Setup or opening this build.
For an installed copy, run the new Setup in the same installation folder.
For a portable copy, extract the new ZIP into a fresh folder.
Leave Documents/Beam in place:
the app reuses existing files, history and pairing. Updating does not rotate the
token unless you choose Reset pairing. Refresh Safari to load the updated page.

CONNECTION HELP
Refresh the PC address list after changing networks. The QR follows the selected
adapter. Local connection checks test the PC server, not the phone's route or
router/firewall settings. Do not disable the firewall globally.
Safari offers Retry connection and rechecks when you return to the page.
PC activity reflects a recently active remote browser, not proof of delivery.
Hidden Safari pages stop heartbeats; activity expires after about 15 seconds.
After the PC's IP changes, scan a fresh QR. Copied diagnostics omit the token
and private transfer contents, but include the selected local IP and port.

Shortcuts is NOT required. The optional Share Sheet Shortcut remains supported.
Uploads are limited to 100 MB per file and notes to 64 KB of UTF-8 text.
Keep Safari open during transfers. Check the result of each item in Uploads.
Cancelling or losing a response does not prove the PC did not save the item.
In Safari, use Retry on the original upload row: Beam checks the saved receipt
first and reuses that transfer ID. Already received items are not uploaded again.
Selecting the file again starts a NEW transfer. Clearing finished rows or
reloading/closing the page loses their retry IDs. Queues are not resumed after
reload. The optional legacy Shortcut does not have safe-retry protection.
Refresh Safari after updating the PC build to load the current retry code.

RESET PAIRING
On the PC, open Pair phone, choose Reset pairing, and confirm. Scan the new QR
on each browser. Update any Shortcut's X-Beam-Token header from the new PC token.
Every old browser, QR and Shortcut loses access; active transfers may stop.
Vault files, history and receipts are kept. After re-pairing, Retry the original
Safari upload row to check its receipt. Already copied/saved data stays on the
phone. A reset error leaves the previous pairing working.

WINDOWS CONTROLS
Pill mode keeps a small widget on-screen. Minimize uses the taskbar.
Hide to tray keeps Beam receiving. Close / Quit stops Beam completely after
active desktop queue work finishes.

WINDOWS STARTUP AND UNINSTALL
Choose Start Beam with Windows in Setup or in the tray/pill menu. Sign-in launches
stay in the tray with receiving active. Use Open Beam from the tray to show the
workspace. Windows Settings > Apps > Startup can override or delay this option.
If a portable folder moves, turn startup off before moving it, then enable it
from the new copy. Only one Beam instance can run in a Windows session.
Quit Beam before upgrading or uninstalling. Uninstall from Windows Installed Apps.
Uninstall keeps Documents/Beam, including files, history and pairing. A portable
ZIP has no uninstaller; disable its startup option before removing its folder.

DATA AND SECURITY
Files and notes are stored under Documents/Beam on the Windows account.
This alpha uses unencrypted local HTTP and a shared pairing token. Use only
on a trusted local network. Never port-forward Beam or expose it to the internet.
Do not share your pairing QR, token, private files, or history.json.

This development build is unsigned. Windows may show a security warning.
Only run a download whose source and checksum you trust; do not disable Windows
security globally. The app and installer are unsigned alphas; production
security hardening is not included. The Windows executable is x64.
